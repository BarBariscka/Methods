# Задания по лабораторным работам

> **Репозиторий:** https://github.com/Voyager7777/evo-ai-agents-labs

Курс: разработка AI-агентов и MCP-серверов для платформы [AI Agents](https://cloud.ru/products/evolution-ai-agents) на облаке Evolution (cloud.ru).

Каждое задание содержит: цель, перечень задач, требуемый результат, форму отчёта и контрольные вопросы. Нумерация лабораторных соответствует каталогам репозитория.

## Лабораторная работа 1. MCP-сервер финансовых расчётов (Python)

**Каталог:** `lab1-mcp-finance-lab/`

### Цель
Освоить разработку MCP-сервисов (Model Context Protocol) на Python с использованием FastMCP: описание инструментов, валидация входных данных, тестирование, контейнеризация и развёртывание в облаке.

### Задания
1. Изучить структуру проекта и назначение модулей: `server.py`, `calculations.py`, `validators.py`, `config.py`, `metrics.py`.
2. Разобраться в реализации инструментов:
   - `loan_schedule_annuity` — аннуитетный кредит (фиксированный платёж, помесячный график);
   - `loan_schedule_differential` — дифференцированный кредит;
   - `deposit_schedule_compound` — вклад с ежемесячной капитализацией и взносами;
   - `compare_loan_schedules` — сравнение двух схем погашения.
3. Запустить сервер локально: `uv run python src/server.py` (порт 8000) и проверить работу инструментов через любой MCP-клиент.
4. Прогнать тесты: `PYTHONPATH=src uv run pytest test/` (18 тестов). Разобраться, что покрывают `test_calculations.py` и `test_validators.py`.
5. **Самостоятельное задание:** добавить новый инструмент `investment_calculator` — расчёт доходности инвестиций с ежемесячным пополнением (вход: начальная сумма, ежемесячный взнос, ставка, срок; выход: итоговая сумма и график). Написать для него валидатор и не менее 3 тестов.
6. Собрать Docker-образ и развернуть MCP-сервер в AI Agents (cloud.ru), подключить его к агенту.

### Результат
- Работающий MCP-сервер с 5 инструментами (4 исходных + 1 новый).
- Пройденные тесты, Docker-образ, развёрнутый сервис в облаке.

### Контрольные вопросы
1. Что такое MCP и зачем он нужен AI-агентам?
2. Как FastMCP превращает Python-функцию в инструмент? Какую роль играют type hints и docstring?
3. Чем аннуитетный платёж отличается от дифференцированного (формулы)?
4. Зачем нужен отдельный слой валидации входных данных?
