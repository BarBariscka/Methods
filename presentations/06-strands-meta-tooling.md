## 2. Теоретическая часть

### Что такое meta-tooling

Meta-tooling — способность AI-системы создавать новые инструменты во время выполнения.
Цикл работы агента:

1. Анализирует запрос пользователя.
2. Определяет, что готового инструмента недостаточно.
3. Создаёт новый инструмент (пишет код).
4. Загружает инструмент в свою систему.
5. Использует созданный инструмент для решения задачи.

### Отличие от статического набора инструментов

| | Статические инструменты | Meta-tooling |
|---|---|---|
| Когда появляются | На этапе разработки | Во время работы агента |
| Ограничения | Жёсткий список заранее заданных функций | Агент сам создаёт нужные функции |
| Расход ресурсов | Предсказуем | Выше: создание кода и загрузка |
| Требует | — | Изоляция выполнения, `tools/` в образе |

### Мета-инструменты Strands

- **`editor`** — создаёт и редактирует файлы с кодом инструментов.
- **`load_tool`** — загружает созданный инструмент в систему агента.
- **`shell`** — выполняет shell-команды для отладки.

### Риски выполнения сгенерированного кода

- выполнение произвольного кода, созданного моделью;
- запуск shell-команд с правами контейнера;
- изменение состояния агента необратимым способом.

**Меры ограничения:** изоляция контейнера, sandbox-исполнение, отсутствие доступа
к файловой системе хоста, лимиты итераций, аудит действий агента.

## 5. Ключевые инженерные решения

### Подключение к MCP

```python
# src/agent.py
from strands import Agent
from strands.tools.mcp.mcp_client import MCPClient
from mcp.client.streamable_http import streamablehttp_client
from strands.tools import load_tool, editor, shell

def create_mcp_transport(mcp_url: str):
    """Создает транспорт для подключения к MCP серверу."""
    # Убеждаемся, что URL заканчивается на /mcp/ для streamable HTTP
    if not mcp_url.endswith('/'):
        mcp_url = mcp_url.rstrip('/')
    if not mcp_url.endswith('/mcp'):
        mcp_url = f"{mcp_url}/mcp"
    return streamablehttp_client(f"{mcp_url}/")

def get_mcp_tools(mcp_urls: Optional[str]) -> tuple[List, List[MCPClient]]:
    tools = []
    mcp_clients = []

    for mcp_url in (mcp_urls or "").split(','):
        mcp_url = mcp_url.strip()
        if not mcp_url:
            continue
        try:
            transport = create_mcp_transport(mcp_url)
            mcp_client = MCPClient(transport)
            # Контекстный менеджер для получения инструментов
            with mcp_client:
                tools.extend(mcp_client.list_tools_sync())
                mcp_clients.append(mcp_client)
        except Exception as e:
            logger.warning(f"Failed to load tools from {mcp_url}: {e}")

    return tools, mcp_clients
```

> Нормализация URL критична: streamable HTTP ожидает адрес, оканчивающийся на `/mcp/`.
> Ошибки загрузки ловятся и логируются — агент продолжает работать с доступными инструментами.

### Сборка агента

```python
def create_strands_agent(mcp_urls: Optional[str] = None):
    from litellm import completion

    def llm_call(messages, **kwargs):
        response = completion(
            model=os.getenv("LLM_MODEL", "gpt-4"),
            messages=messages,
            api_base=os.getenv("LLM_API_BASE"),
            api_key=os.getenv("LLM_API_KEY"), **kwargs)
        return response.choices[0].message.content

    system_prompt = os.getenv("AGENT_SYSTEM_PROMPT",
                               TOOL_BUILDER_SYSTEM_PROMPT)

    # Базовые мета-инструменты (если доступны)
    tools = [load_tool, editor, shell] if _HAS_META_TOOLS else []

    # Инструменты из MCP серверов
    mcp_tools, mcp_clients = get_mcp_tools(mcp_urls)
    tools.extend(mcp_tools)

    agent = Agent(system_prompt=system_prompt, tools=tools, llm=llm_call)
    agent._mcp_clients = mcp_clients
    return agent
```

### Системный промпт создателя инструментов

```python
TOOL_BUILDER_SYSTEM_PROMPT = """
Ты агент, который может создавать новые инструменты на лету и использовать
инструменты из MCP серверов.

Когда пользователь просит создать инструмент:
1. Определи следующую доступную версию инструмента (custom_tool_0, custom_tool_1, и т.д.)
2. Создай файл tools/custom_tool_X.py с правильной структурой
3. Используй инструмент load_tool для загрузки нового инструмента
4. Сообщи пользователю, что инструмент создан и готов к использованию

Структура инструмента должна следовать формату:
- TOOL_SPEC с описанием инструмента
- Функция с именем custom_tool_X, принимающая ToolUse и возвращающая ToolResult

Всегда создавай инструменты в директории tools/ и используй load_tool для их загрузки.
"""
```

### Формат создаваемого инструмента

```python
from typing import Any
from strands.types.tool_types import ToolUse, ToolResult

TOOL_SPEC = {
    "name": "tool_name",
    "description": "Что делает инструмент",
    "inputSchema": {
        "json": {
            "type": "object",
            "properties": {
                "param_name": {
                    "type": "string",
                    "description": "Описание параметра"
                }
            },
            "required": ["param_name"]
        }
    }
}

def tool_name(tool_use: ToolUse, **kwargs: Any) -> ToolResult:
    tool_use_id = tool_use["toolUseId"]
    param_value = tool_use["input"]["param_name"]

    result = process(param_value)

    return {
        "toolUseId": tool_use_id,
        "status": "success",
        "content": [{"text": f"Result: {result}"}]
    }
```

**Правила, которые должен соблюдать агент:**

1. Имя функции должно **совпадать** с `name` в `TOOL_SPEC`.
2. Функция принимает `tool_use: ToolUse` и возвращает `ToolResult`.
3. Все импорты должны быть корректны.
4. Файл создаётся в каталоге `tools/`.

## 10. Типичные ошибки и решение

| Проблема | Причина | Решение |
|---|---|---|
| Агент не создаёт инструменты | Слабый системный промпт | Проверить `TOOL_BUILDER_SYSTEM_PROMPT`, задать `AGENT_SYSTEM_PROMPT` |
| Ошибка загрузки инструмента | Имя функции ≠ `name` в `TOOL_SPEC` | Сделать имена идентичными |
| Ошибки импорта в созданном файле | Неверные зависимости | Проверить импорты, доступность пакетов в образе |
| Каталог `tools/` недоступен | Не создан в образе | Создать `tools/` при сборке Dockerfile |
| Агент не подключается к MCP | Неверный URL или транспорт | URL должен заканчиваться на `/mcp` или `/mcp/`, сервер должен поддерживать streamable HTTP |
| Несовместимость с платформой | Файловая система в рантайме ограничена | Предусмотреть in-memory хранилище либо учесть ограничения платформы |

> ⚠️ **Важно:** в AI Agents агенты не должны работать с файловой системой в рантайме.
> Для meta-tooling это ограничение может потребовать специальной обработки
> или использования in-memory хранилища.
