## 2. Теоретическая часть

### Три сущности CrewAI

| Сущность | Что задаёт |
|---|---|
| **Agent** | `role` (персона), `goal` (цель), `backstory` (контекст), `tools`, `allow_delegation` |
| **Task** | `description` (что сделать), `agent` (кто делает), `expected_output` (что получить) |
| **Crew** | Список агентов и задач, `process` (стратегия выполнения), `verbose` |

### Процессы выполнения

- **`Process.sequential`** — задачи выполняются по порядку, каждая следующая может
  использовать результат предыдущей.
- **`Process.hierarchical`** — выделяется менеджер (обычно агент с `allow_delegation=True`),
  который динамически распределяет задачи между специалистами.

### Делегирование

Флаг `allow_delegation=True` позволяет агенту передавать задачи другому агенту или
эскалировать задачу менеджеру. В примере лабораторной работы координатор умеет делегировать,
а исполнитель — нет (`allow_delegation=False`), чтобы избежать «петли» задач.

### Когда мульти-агентный подход полезен

**Плюсы:** разделение экспертизы, параллельная проработка аспектов, более структурированные
выводы, «критик» отсеивает слабые результаты.

**Избыточен, когда:** задача простая и решается одним вызовом инструмента; добавление агентов
только увеличивает расход токенов и время ответа.

## 5. Ключевые инженерные решения

### Кастомный инструмент для CrewAI

```python
# src/agents.py
from crewai.tools import BaseTool

class MCPTool(BaseTool):
    """CrewAI Tool для работы с MCP инструментами."""
    name: str
    description: str
    mcp_url: str
    tool_name: str

    def _run(self, input_text: str) -> str:
        """Синхронный вызов MCP инструмента."""
        async def async_call():
            async with httpx.AsyncClient(timeout=30.0) as client:
                response = await client.post(
                    f"{self.mcp_url}/tools/{self.tool_name}/invoke",
                    json={"input": input_text},
                    headers={"Content-Type": "application/json"})
                response.raise_for_status()
                result = response.json()
                return str(result.get("content", result))
        return asyncio.run(async_call())
```

`MCPTool` наследует `BaseTool` и выполняет HTTP-вызов MCP-сервера — так MCP-инструменты
становятся «родными» инструментами CrewAI.

### Определение агентов

```python
coordinator = Agent(
    role='Координатор',
    goal='Координировать работу команды и распределять задачи',
    backstory='Опытный координатор, который умеет эффективно '
              'распределять задачи между специалистами.',
    verbose=True,
    allow_delegation=True,      # ← может делегировать задачи
    llm=llm_call)

executor = Agent(
    role='Исполнитель',
    goal='Выполнять задачи используя доступные инструменты',
    backstory='Квалифицированный специалист, который умеет '
              'использовать инструменты для решения задач.',
    tools=tools,                # ← MCP-инструменты доступны только здесь
    verbose=True,
    allow_delegation=False,     # ← делегирование запрещено
    llm=llm_call)
```

Обратите внимание: **инструменты подключены только к исполнителю**. Координатор
планирует, исполнитель действует. Это типичное разделение ответственности.

### Задачи и сборка crew

```python
# src/tasks.py
def create_tasks(agents):
    coordinator, executor = agents

    analyze_task = Task(
        description="Проанализируй запрос пользователя и определи, "
                    "какие инструменты нужны для его выполнения",
        agent=coordinator,
        expected_output="Список необходимых инструментов "
                        "и план выполнения задачи")

    execute_task = Task(
        description="Выполни запрос пользователя используя "
                    "доступные инструменты",
        agent=executor,
        expected_output="Результат выполнения запроса "
                        "с детальным ответом")

    return [analyze_task, execute_task]

# src/crew.py
def create_crew(mcp_urls: str = None):
    agents = create_crew_agents(mcp_urls)
    tasks = create_tasks(agents)
    crew = Crew(agents=agents, tasks=tasks,
                process=Process.sequential,   # последовательное выполнение
                verbose=True)
    return crew
```

## 10. Типичные ошибки и решение

| Проблема | Причина | Решение |
|---|---|---|
| Crew не выполняет задачи | Неверные определения агентов или задач | Проверить агенты, задачи, системные промпты, процесс выполнения |
| Агенты не используют инструменты | Неверный `MCP_URL` или инструменты не подключены | Проверить `MCP_URL`, добавить `tools` агенту-исполнителю |
| Путаница ролей | Размытые `role` / `goal` / `backstory` | Задать чёткие формулировки для каждого агента |
| Долгий ответ | `hierarchical` добавляет дополнительные вызовы LLM | Начать с `Process.sequential` |
| Зацикливание задач | Взаимная делегация агентов | Запретить делегирование у исполнителя |
